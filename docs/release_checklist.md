# Public-release checklist

- [x] Clean standalone package; no dependency on private directory layouts.
- [x] No participant data, survey responses, embeddings, or identifiers.
- [x] No checkpoints, generated study trajectories, or restricted summaries.
- [x] No credentials, environment files, hostnames, or private keys.
- [x] Synthetic-only unit and end-to-end tests.
- [x] Automated release audit in local tests and GitHub Actions.
- [x] Data contract and private-adapter boundary documented.
- [x] Compact/full-scale model distinction documented.
- [x] Citation, attribution, and license files included.
- [ ] Add the final paper DOI and repository URL after publication.
- [ ] Create a GitHub release tag after the authors approve version `0.1.0`.
