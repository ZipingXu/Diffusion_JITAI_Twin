# Attribution and scope

The full-scale model used in the associated study builds on the public
[TimeWeaver-SSSD](https://github.com/YuyiChang/TimeWeaver-SSSD) codebase and,
through it, the SSSD and S4 model families. Consult those projects for their
authorship, citations, and redistribution terms.

This repository contains a compact, independently packaged reference
implementation of the paper's three-stage pipeline. It does not redistribute
the private study data, learned checkpoints, access credentials, or the
full-scale training tree.
